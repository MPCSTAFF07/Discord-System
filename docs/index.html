カメラ接続管理

カメラサーバーへ接続して、選手の送信リンクと接続状況を管理します。

初回の準備
  1. Cloudflare版を公開し、表示されたworkers.devのURLを確認します。
  2. サーバーの接続先URLと管理キーを入力します。
  3. 一覧の「送信リンク」を選手へ渡します。
  4. 「OBS URL」をOBSのブラウザソースへ貼ります。

GitHub Pagesだけではカメラ接続処理は動きません。Cloudflareの設定前は未接続のままです。Discordログインを使う場合も、設定先はカメラサーバーです。

カメラサーバーを設定してください。
